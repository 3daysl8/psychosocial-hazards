Design directions

Three working versions of the guide, each using the real site code and content. Only the page shell and stylesheet differ. Switch jurisdiction, search the hazard library and open a hazard in each. The pattern sample shows components coming in Phases 2 to 5.

Check each at phone width too: in the browser press F12, then the phone icon (Ctrl+Shift+M).

  1. A. Civic

    After Safe Work Australia's Code of Practice pages. White page, large rounded tinted panels, contents sidebar, Montserrat. Familiar to anyone who uses regulator sites. Own blue, no logo, and labelled as an independent guide so it isn't mistaken for official material.

    Home Hazard library Bullying Pattern sample

  2. B. Workshop

    After isaacpeterson.au. Ruled puzzle grid on warm paper, ink rules, tomato offset shadow, highlight blue, Archivo Black, JetBrains Mono and Georgia. Unmistakably yours, and ties the guide to your site and the Risk Model family.

    Home Hazard library Bullying Pattern sample

  3. C. Casebook

    My choice. A quiet, document-like page for someone working carefully through a serious matter they'll print and keep. Serif text on warm paper, numbered indexes instead of card grids, HR and HSR notes in the margin beside the text they relate to.
