# resources/ (editable sources for printable guides)

- Editable sources live here. Finished PDFs go to `site/downloads/` only. Never put research papers in `site/`.
- Every guide uses the shared files in `brand/` and carries the same disclaimer, version number and "current as at" date as the site.
- Each finished guide gets an entry in `site/js/data/resources.js` (title, description, audience, jurisdiction, version, current-as-at).
- All guides are drafts until reviewed by the owner. Legal or regulatory statements use `TODO-VERIFY` (see `docs/content-rules.md`).
