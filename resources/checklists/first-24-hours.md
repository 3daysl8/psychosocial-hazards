# First 24 hours checklist: DRAFT outline

Status: draft, for owner review. Finished PDF built in Phase 9 into `site/downloads/checklists/`.

## Purpose

A one-page checklist for the first day after a psychosocial incident or report, for HR and HSRs to keep at hand.

## Content source (don't copy text here)

From `site/js/data/triage.js` and `site/js/data/flow.js`:

- Support contacts box (`supportContacts`): 000, Lifeline, Beyond Blue, EAP, with a blank line to write in the organisation's EAP number.
- "First steps" checklist (`triage.safety` options), with tick boxes.
- Notifiable incident check: the question, plus the regulator link for the guide's jurisdiction version (Victoria or Model WHS).
- One line: processes can run side by side; the hazard process doesn't wait.
- "What was reported" box with lines to write on.

## Layout

- A4 portrait, single page, prints well in black and white.
- Two jurisdiction versions (Victoria, Model WHS), because the regulator link differs.
- Footer: disclaimer, version, current-as-at date, site URL. Shared brand from `resources/brand/`.
